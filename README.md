# CampusReflex Lite

A modern, redesigned student portal UI built with React + Vite + Tailwind, inspired by real college portals but rebuilt with a cleaner, faster, and more intuitive user experience.

## Features Built So Far
- ✔ Attendance Dashboard (Fully Dynamic)
Total Average Attendance (Auto-calculated)
Defaulters & Good Standing cards
Status color-coded tags
Subject-wise % table
Beautiful reusable UI components

- ✔ Schedule View (In Progress)
Clean calendar layout
Day/time grid inspired by real college systems
Placeholder added — full version coming next

- ✔ Hero Banner
Gradient background
Student info + roll number + department
Reusable component

## 🧩 Tech Stack
React + Vite
TailwindCSS
Lucide Icons
Reusable Components Architecture

## 📌 Upcoming Features
